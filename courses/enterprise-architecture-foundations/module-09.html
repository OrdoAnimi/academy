Module 9 — Current and Target Architecture Views

Theory 20 minutes + Workshop 60 minutes

Duration: 80 minutes. Artefact produced: current and target architecture view set.

Module Overview

What you will learn

Represent current state

Show the existing architecture clearly enough to identify constraints and inherited risk.

Represent target state

Show the intended future architecture as an executable direction, not a wish list.

Connect views to decisions

Explain what each view helps decide.

Show transition logic

Describe the path from current to target without pretending the change is instant.

Theory

Views exist to answer questions

A current-state view explains what exists and why it matters. A target-state view explains what should exist and what decisions must be made to get there. Good architecture views are selective. They omit noise so the decision problem becomes visible.

Workshop

Create a current and target view pair

Use the migration scenario to create a current-state view and a target-state view that show the major business, application, data, and technology changes.

Workshop task

Create one current-state view and one target-state view, then write the transition logic between them.

Assessment prompt

Explain what the target view changes, what it preserves, and what decision it requires.

What to submit

Current view; target view; transition notes; decision statement; top risks.
