Velocity Framework

Certification Pathways

Pilot pathways for applied architecture capability.

Velocity certification pathways are currently in pilot design. They are intended to assess applied architecture capability through artefacts, case work, and practitioner review.

Pilot Design

Planned pathways

Certified Velocity Practitioner

Pilot / Planned

Intended audience: Enterprise, solution, business, and delivery practitioners adopting decision-first architecture.

What is assessed: Intent, decision traceability, guardrails, governance rhythm, and applied artefacts.

Evidence required: Architecture Vision, decision log, options paper, roadmap, and reflective practitioner review.

Certified VAF-SA Practitioner

Pilot / Planned

Intended audience: Solution architects and delivery architects using the VAF-SA practitioner method.

What is assessed: Scoping, board pack creation, solution options, risk visibility, and delivery-ready outputs.

Evidence required: Board pack, solution context, decision rationale, exception log, and practitioner interview.

Certified Velocity AI Practitioner

Pilot / Planned

Intended audience: Architects using AI-assisted methods responsibly in architecture and governance work.

What is assessed: AI-assisted artefact generation, prompt governance, human review, traceability, and ethics.

Evidence required: Prompt record, generated artefact, review notes, governance evidence, and applied case study.

Important note

Pilot status

These pathways are not currently presented as accredited or externally recognised credentials. They are Academy pilot designs for assessing applied capability through evidence, artefacts, case work, and practitioner review.
