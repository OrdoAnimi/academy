Module Pattern

Every module produces evidence

Academy modules use a reusable structure: learning outcome, enterprise delivery relevance, core concepts, exercise, artefact or evidence, related framework concepts, related tools, and next module.

Learn

Concept to decision

Practitioners learn the concept only far enough to use it in a governed delivery decision.

Practise

Scenario to artefact

Exercises convert delivery situations into briefs, options, roadmaps, decision logs, and review evidence.

Operate

Artefact to ecosystem

Outputs connect to framework guidance, artefact generators, readiness scoring, and governance portals.
